Tests of Redis 7.4 and 8 commands (HEXPIRE and the like) fail on the control too, so they aren't here.
redis-rb won't start without a Unix socket, so its Tantalum run has socat in front of the port: Tantalum
has no Unix sockets, and that's in no count above. node-redis's server options are dropped for Tantalum
but for --requirepass.

Most of the lost tests looked at come down to a command or a setting that isn't there: the pub/sub test that
kills a connection looks for cmd=subscribe in CLIENT LIST; XADD's LIMIT test reads a setting with CONFIG GET;
TOUCH's reads OBJECT IDLETIME; scan's are DEBUG POPULATE; and a node-redis pool test is CLIENT TRACKING. Not
every lost test was read one by one. Answers that do differ from Redis': COMMAND's entries have no ACL
categories, key specifications or tips (COMMAND DOCS is empty); SAVE, BGSAVE and BGREWRITEAOF refuse without
--snapshot or --aof, where Redis saves to its default.
