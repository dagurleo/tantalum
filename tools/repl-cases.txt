# Where Tantalum propagates more than Redis, so that replicas have what the
# master has (Redis' don't): a consumer a group read made, that read nothing,
# goes as XGROUP CREATECONSUMER (from Redis, nothing); so does one XCLAIM or
# XAUTOCLAIM made that claimed nothing.
#   XGROUP CREATE x g $ / XREADGROUP GROUP g c STREAMS x >

!XREADGROUP GROUP g c STREAMS x >
